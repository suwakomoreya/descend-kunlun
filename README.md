# Descending Kunlun
You're a human resident of Mount Kunlun and rumors are spreading of a garden of heavenly peaches near the peak of the mountain. Fortunately, you're a weirdo who lives UP in the mountains.
However, to enter these gardens you must bring five jade pieces for the Queen of Mother West. 

---
Scattered around the mountains from top to bottom lies multiple hidden gifts scattered by a mischiveous monkey. Collect these jade pieces to unlock the gates and enter the garden of peaches.
-
Controls:
A and D to move left and right. Same for left and right arrow keys.
W, space, or arrow up to jump.
Enter in the menu to select.
Escape to exit game or exit tutorial.

Features: 
- Savepoints (i lied they actually dont save theyre more like checkpoints)
- Spikes (avoid these!!!! theyll send you back to your checkpoint)
- Hidden jades (theyre hiding in the trees looking at you)

Libraries used:
Nlohmann json to parse map data
Raylib library 

Compilation:
Have some sort of C++ compiler, and make sure youre using C++ 17+. (im using c++20)
